Intalling Microtrait

1. Software dependencies

In the HPC3:
conda env create -f microtrait.yml
conda activate microtrait
Here we have install all the software dependencies from https://github.com/ukaraoz/microtrait. We just need to add the R dependencies and data dependencies.
